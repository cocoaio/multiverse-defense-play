# 多元防线

一个可安装为 PWA 的多场景竖屏自动射击 Roguelike 游戏原型。

微信试玩地址：`https://multiverse-defense-play.fullunull.chatgpt.site/`

## 本地运行

在本目录执行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

也可以直接双击 `index.html`。全部战斗角色使用本地 2D 图集，`file://` 模式也能正常运行。

## 当前内容

- 6 个连续章节：沦陷都市、极地雪原、隔离医院、近地轨道、火星前哨、月面遗迹
- 每章 12 关，共 72 关；章节内逐关推进，跨主题需解锁对应主题装扮
- 独立的「太虚仙域」无尽模式开局即开放：三条命、无限境界、动态修为匹配和广告演示复活；新角色前五重天获得护道加持，首个 Boss 只高一小境界，之后再逐步解除保护
- 七个场景全部使用独立高精度俯视战场画布：城市十字路口、冰湖营地、隔离病区、轨道甲板、火星前哨、月面基地和仙门云台；不再使用换色格子地图
- 城市、雪原、医院、火星、月面各有三名专属高精度职业角色，轨道模式使用三艘独立舰艇，修仙模式使用独立修士图集
- 全部章节的局内角色统一使用主题 2D 图集，不再加载 3D/WebGL 模型；主角与敌人处于同一 Canvas 世界层，并按脚底位置进行自然前后遮挡
- 仓库已移除停用的 GLB、Blender 工程和 Three.js 加载管线；桌面优先使用 WebP，微信与部分安卓浏览器自动切换 PNG/JPEG 兼容素材，并在开战前完成关键图集解码
- 临时背景音乐已全部移除，当前仅保留可独立静音的战斗与界面音效，后续接入正式 DJ 曲库
- 修仙大厅、职业选择和战斗共享同一套独立角色图集；三职业按各自图集区域渲染，不会串入相邻角色衣袖或武器
- 大厅主角、关卡预览与职业选择按各主题图集的真实身材比例展示，避免头部、武器或脚部被固定容器裁切
- 每个世界使用限定职业：医院为隔离区重装员、抗体战地医生和生化研究员，其他世界也分别使用符合城市、雪原、轨道、火星、月面的身份与技能命名
- 无限滚动地图与主题地貌持续生成；角色会被建筑、营地及地图边缘实体自然阻挡，并留下脚印或地面接触反馈
- 战士、远战、法师三种职业：战士高血近战，远战均衡生命与超长射程，法师低血高伤
- 普通、冲刺、护盾、分裂、召唤型 Boss 等机制型敌人
- Boss 范围杀招会明确显示倒计时、预计伤害和重创效果；命中地形后会按主题留下雪坑、城市废墟、舰体破口、熔岩坑或道场裂隙
- 基础强化、职业专精与御兽真经、万剑匣、浩然护体阵、九天雷劫、功德金莲、两仪符域等修炼路径；无尽模式所有强化均可持续升重
- 七个世界 × 三种职业共 21 套主题终极技能：动力刃、电网、雪崩、消杀、舰首冲击、轨道炮、熔岩断层、引力坍缩、万剑与雷劫等均有独立蓄力、预警、爆发和余波
- 角色使用上下身与左右腿分层动作，包含交替跨步、身体惯性、攻击重心、近战挥斩、远程后坐、工程设备展开或修士结阵
- 21 种普通攻击拥有独立武器语言：近战只显示手持武器挥砍或盾牌前推，不再发射通用能量团；枪弹、冰矛、针剂、激光、轨炮、飞剑、符箓与工程设备均使用独立弹道
- 人物攻击直接驱动原角色贴图里的武器与上半身，不再叠画第二把程序武器；修仙剑修改为慢攻速、高伤害、宽判定的半月剑气
- 攻击机制也按主体拆分：无人机追踪、磁轨与飞剑穿透、冰系减速、特斯拉连锁、血清与等离子溅射、抗体回复、月面击退和引力牵引均独立生效
- 七大主题、三种职业均拥有独立的三段技能成长路径；核心技能与对应联动技能组合后会暗中觉醒质变效果，例如猎手专注与极速装填会形成高速贯穿弹链
- 命中反馈固定在敌人表面接触点，包含受力形变、定向后退和材质化火花/冰片/机械碎屑，不再使用统一圆球爆炸
- 穿透攻击取消全局命中顿帧，并使用敌群空间分区碰撞；粒子、飘字、经验晶体和弹道均设有动态预算，低帧率时自动降低非关键特效密度
- 普通攻击不显示锁定线或范围圈；只有 Boss 范围杀招显示明确的地面预警区，敌群新增保持距离射击的弓手与施法者
- 修仙境界以玩家当前修为为中心匹配，越阶敌人低概率出现但拥有显著强度差；御兽、万剑匣、浩然护体阵和九天雷劫使用持续可见的强化特效
- 敌人死亡后在原地留下经验晶体；角色必须主动靠近吸附并拾取，未拾取的经验不会用于升级
- 升级不再自动回血，只刷新大招；普通小怪约 10% 概率掉落急救血包，拾取后恢复最大生命的 20%
- 三只永久随行宠物使用独立高精度 2D 图集并可在军械库切换：赤焰灵狐持续追踪输出、玄甲战獒负责重击、青萝药灵将血包掉率提高至 15%
- 每个普通关卡拥有独立击杀目标，必须同时完成目标并击败 Boss；近战敌人会沿弧线包抄并持续追击
- 装备低概率掉落，高品质随章节推进逐步开放；Boss 高概率掉落，掉落装备绑定当前职业
- 三职业分别拥有独立六部位养成栏，职业武器只作为战斗动作的一部分，不再保留独立武器收藏栏
- 六部位装备、四档品质、60 格仓库与最高 +10 强化；支持单件或一键卸下，实时显示综合战力、属性汇总和战力增减反馈
- 战略无人机只在第一章第 1、2 关投送职业专属限时神装；第 2 关完成体验后通过奖励广告永久解锁，后续普通关卡不再重复投箱。神装可无限强化、每级费用翻倍，跨越推荐章节后同步率会下降
- 第一关拾取神器会触发全屏觉醒演出和超高试玩加成；通关第二关自动弹出永久解锁广告。未解锁神器挑战第一章终章时会遭遇神性装甲战力墙，阵亡后可通过奖励广告永久解锁、满血复活并开启本局横推神威
- 本地 `file://` 版本自动显示网页管理员身份并解锁全部章节关卡；HTTP 版本可使用 `?admin=owner` 进入同一管理视图，普通玩家仍遵循正常解锁进度
- 当前装备仅提供数值加成，不再用通用装备贴层覆盖场景角色的职业造型
- 全部武器皮肤直接开放，可在角色试衣预览中即时查看
- 本地补给币、体力、八条永久成长线、演示广告和测试充值通道；环卫无人机群在非修仙地图通用
- 第一章使用六套独立高精度丧尸图：感染者、防暴尸、迅捷尸、毒爆胖尸、远程变异体和巨型首领；仙域使用剑修、符修、体修、御兽修、魔修和宗主六套真人修士图
- 丧尸血肉残躯、病毒溶解物、飞船/机甲残骸、灵体余烬等场景化慢速消散效果
- 仙域主角、剑修、符修、体修、魔修、宗门护法和宗主均使用精细人形角色图集
- 七个世界分别使用城市荧绿、雪原冰蓝、医院青白、轨道紫蓝、火星赤橙、月面银灰与仙域墨金 UI 主题
- 近景战斗镜头、开局敌群与可视范围锁敌重新校准；医院加入消毒走廊、医疗床、输液架、生化警示与动态扫描光
- 背景音乐保持关闭，后续接入正式授权曲库；当前只保留战斗与界面音效开关
- 结算、音效、震动、带退出本局操作的暂停页和离线缓存
- Service Worker 使用 v45 分级缓存策略：界面代码优先联网更新，角色/背景图集缓存优先；单个素材失败不会再导致整次离线缓存安装失败

## 操作

- 桌面端角色自动感应鼠标方向移动；手机端使用跟手的浮动起点拖动，支持移动时用第二根手指释放大招（仍保留键盘方向键）
- 武器自动锁定射程内最近敌人并持续攻击
- 开局选择战士、远战或法师流派；军械库外观不会提供付费数值优势
- 升级时点击一张补给卡
- 点击底部职业大招，或按空格键释放专属终极技能
- 拾取经验升级时只刷新大招，不再恢复生命；回血主要来自主动拾取血包、宠物增益和专门的恢复科技
- 按 `P` 暂停/继续

## 商业化原型说明

当前“充值”和“广告”均为前端演示流程：测试购买不会产生真实扣款，演示广告也未连接广告平台。正式发布前需要接入服务端订单校验、Apple/Google 等平台内购和正式激励广告 SDK。
